# Эйдос (IDOS) 2.5.6

IDOS — настольный голосовой ИИ-агент для Windows 10/11. Он сочетает чат и голосовой ввод с инструментами для работы с окнами, экраном, файлами, браузером и приложениями Windows. В верхней части экрана работает настраиваемый прозрачный «остров» с состоянием агента, быстрым доступом к чату, уведомлениями и мультимедиа.

> Важно: IDOS может управлять компьютером от имени текущего пользователя. Перед использованием ознакомьтесь с разделом [Безопасность](SECURITY.md), особенно с режимами автономности и выполнением команд.

## Что умеет

- Принимать задачи текстом или голосом, вести историю чатов, выполнять многошаговые задачи и проверять результаты действий.
- Находить, запускать и переключать Windows-приложения; читать элементы окон через UI Automation, нажимать кнопки, вводить текст и использовать горячие клавиши.
- Делать снимки экрана, читать видимый текст через OCR, находить элементы по надписи или изображению, распознавать QR-коды и выбирать цвет.
- Искать и читать веб-страницы; управлять браузером Playwright, вкладками и загрузками.
- Читать поддерживаемые документы, находить и изменять файлы, выполнять PowerShell/cmd/Python-команды.
- Создавать повторно используемые сценарии автоматизации и навыки-инструкции.
- Хранить локальные чаты, заметки, напоминания, буфер обмена и пользовательскую память; показывать карточки и таймеры на острове.
- Предоставлять голосовой ответ через локальный Silero TTS; распознавать речь через установленный локальный GigaSTT или настроенный облачный STT.
- Подключать внешние MCP-серверы и дополнительные функции острова: мультимедиа, погоду, состояние системы, запись экрана и интеграции.

Наличие отдельной функции зависит от Windows, установленных компонентов, разрешений и настроек. Необязательная функция может быть отключена, если её зависимость отсутствует.

## Быстрый запуск из исходников

Требуются Python 3.11, Node.js 20+, Rust stable с MSVC Build Tools, WebView2 и Windows 10/11. Интернет нужен для установки пакетов, браузера Playwright и моделей/облачных функций.

```powershell
powershell -ExecutionPolicy Bypass -File scripts\Setup.ps1
Start-IDOS.bat
```

При первом запуске Tauri компилирует настольную оболочку. После запуска добавьте ключ выбранного провайдера в интерфейсе «Ключи и модели»; в конфигурации по умолчанию указана модель `groq:openai/gpt-oss-120b`. Ключ нужен для облачного провайдера; доступность модели определяется провайдером и вашим аккаунтом.

Подробная пошаговая инструкция, включая голосовой ввод, обновление и устранение неполадок: [INSTALL.md](INSTALL.md).

## Горячие клавиши по умолчанию

| Действие | Клавиши |
|---|---|
| Голосовой вопрос | `PageUp` |
| Командная строка | `Alt+Space` |
| Показать или раскрыть остров | `Ctrl+Alt+I` |
| Окно чата | `Ctrl+Alt+A` |
| Диктовка в активное окно | `Ctrl+Alt+D` |
| Буфер обмена | `Ctrl+Alt+V` |
| Скриншот области / всего экрана | `Ctrl+Alt+S` / `Ctrl+Alt+Shift+S` |
| OCR / QR / пипетка цвета | `Ctrl+Alt+O` / `Ctrl+Alt+Q` / `Ctrl+Alt+C` |
| Запись экрана | `Ctrl+Alt+R` |
| Остановить работу агента | `Ctrl+Alt+X` |

Горячие клавиши настраиваются в интерфейсе. Остановка агента не отменяет уже совершённые внешние действия.

## Технологии и устройство

- **Python 3.11** — ядро агента, провайдеры моделей, инструменты, сценарии, локальный API, голос и хранение.
- **JavaScript/CSS и Vite** — интерфейс острова, чата, настроек и выбора области экрана.
- **Rust и Tauri 2** — окна приложения, системный трей, глобальные сочетания клавиш и интеграция с Windows.
- **SQLite и JSON** — локальная история, память, заметки, настройки и служебные данные.
- **WebSocket на `127.0.0.1`** — связь окон интерфейса с Python-ядром; доступ проверяется случайным токеном.

Подробнее: [архитектура проекта](ARCHITECTURE.md) и [безопасность и приватность](SECURITY.md).

## Разработка и проверки

```powershell
# Python-тесты
.venv\Scripts\python -m unittest discover -s tests

# Сборка веб-интерфейса
npm run build

# Проверка Rust/Tauri
cd src-tauri
cargo check --locked
cd ..

# Переносимая сборка: тесты, Vite, Tauri и каталог release
powershell -ExecutionPolicy Bypass -File scripts\Build-Release.ps1
```

Демо ядра без действий на компьютере можно запустить командой `.venv\Scripts\python -m core --demo`; для полного сценария откройте локальный интерфейс с параметрами, указанными в `data/runtime/core.json`. Самопроверка: `Selftest-IDOS.bat` или «Настройки → Самопроверка».

В репозитории настроен CI для Python-тестов на Windows, сборки Vite и `cargo check`: `.github/workflows/ci.yml`.
