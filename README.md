# Эйдос (IDOS) 2.0

> Подробная инструкция по установке: [INSTALL.md](INSTALL.md)

Голосовой ИИ-агент для Windows 11 с «островом» в стиле [Island](https://github.com/exuupery/island): чёрная капсула вверху экрана, которая плавно перетекает в плеер, ход работы агента, уведомления, таймеры, запись экрана и командную строку.

## Установка (VM, `C:\IDOS-AI-AGENT`)

1. Python 3.11, Node 20+, Rust (stable), WebView2.
2. `powershell -ExecutionPolicy Bypass -File scripts\Setup.ps1` (venv, пакеты, `npm install`, Chromium для Playwright, ffmpeg).
3. `Start-IDOS.bat`. Первый запуск компилирует Tauri, это займёт несколько минут.
4. «Ключи и модели»: вставьте ключи Groq, по одному на строку. Модель по умолчанию: `groq:openai/gpt-oss-120b`.
5. Самопроверка: `Selftest-IDOS.bat` или «Настройки → Самопроверка».

GigaSTT (`tools\gigastt\bin`, порт 9876) запускается автоматически, если он установлен.

## Остров: визуальные фишки

- Капсула-«пилюля» с пружинными переходами между режимами (часы → музыка → агент → ответ → панель).
- Подглядывание: капсула чуть увеличивается при наведении; открывается по наведению или клику.
- Музыка: обложка, эквалайзер, строка текста песни прямо в капсуле, свечение по краю цветом обложки в такт басам.
- Раскрытый плеер на фоне размытой обложки; виджеты: часы, погода, батарея.
- Карточки уведомлений «вытекают» из капсулы: напоминания, скриншоты, загрузки, подтверждения действий.
- «Жидкий» персонаж-шар меняет цвет и ритм по состоянию: думает, действует, говорит, слушает.
- Окно не крадёт фокус, а клики по пустому месту проходят насквозь. Скрывается в полноэкранных приложениях и на записях экрана.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Голосовой вопрос | PageUp |
| Командная строка | Alt+Space |
| Показать/раскрыть остров | Ctrl+Alt+I |
| Окно чата | Ctrl+Alt+A |
| Диктовка в любое окно | Ctrl+Alt+D |
| Буфер обмена | Ctrl+Alt+V |
| Скриншот области / экрана | Ctrl+Alt+S / Ctrl+Alt+Shift+S |
| OCR / QR / пипетка | Ctrl+Alt+O / Q / C |
| Запись экрана | Ctrl+Alt+R |
| Аварийная остановка агента | Ctrl+Alt+X |

Все сочетания меняются в «Настройки → hotkeys».

## Голосовые команды

- «Эйдос, переключись на …»: смена модели.
- Любая задача обычной речью, например «открой блокнот и напиши список покупок» или «найди в интернете…».

## Разработка

- Тесты ядра: `.venv\Scripts\python -m unittest discover -s tests`.
- Демо без Windows и ключей: `python -m core --demo`, затем откройте `index.html?view=island&port=…&token=…` (данные из `data/runtime/core.json`) и вызовите `demo.play`.

## Сверка с Island (v2.1)

В репозитории exuupery/island выложены только README и картинки, исходников нет, поэтому сверял по описанию.

Добавлено в v2.1:
- **Жидкий край** (`src/fluid.js`): нижний край капсулы тянется к курсору, под музыку выпускает шипы цвета обложки (низкие частоты слева, высокие справа), роняет каплю, когда что-то удалось (карточка ok, готовый ответ, скриншот), провисает, если вас нет больше 2 минут, и капает в дождь или снег.
- **Пилюля в покое**: время по центру, рядом батарея, справа температура. Слева точки микрофона и камеры (клик выключает микрофон), Caps Lock, раскладка при переключении, VPN.
- **Музыкальная пилюля** `island.music_pill`: `normal` (обложка + эквалайзер), `wide` (название, полоска времени, строка песни с подсветкой как в караоке), `mini` (мини-плеер с кнопками).
- **Громкость колесом мыши** над пилюлей (`status.volume`).
- **Автоскрытие** `island.auto_hide`: остров уходит за край экрана, возвращается, когда курсор упирается в верхний край.
- **Персонажи** `island.character`: `liquid` (по умолчанию), `eyes` (глаза следят за курсором, моргают, засыпают, когда вас нет), `pixel`, `spark`, `cube`, `dot`.
- Режим «сквозь» (`island.through_mode`): остров виден, но клики проходят насквозь.

Ещё не повторено: 25 персонажей и галерея, вкладки «Полка», «Текст», «Заметка», «Управление», «Погода», разметка скриншотов, Imgur/ImgBB.
