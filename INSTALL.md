# Установка и настройка Эйдоса (IDOS) 2.5.6

Это руководство описывает запуск IDOS из исходной папки проекта на Windows 10/11. Перед первым использованием прочитайте [Безопасность и приватность](SECURITY.md): по умолчанию агент работает с высокой автономностью и может управлять вашим компьютером.

## 1. Требования

| Компонент | Требование | Для чего нужен |
|---|---|---|
| Windows | Windows 10/11 | Настольная оболочка и функции управления ПК |
| Python | 3.11 | Ядро агента и Python-пакеты |
| Node.js | 20 или новее | Vite, Tauri CLI и интерфейс |
| Rust | stable (MSVC toolchain) | Сборка оболочки Tauri |
| Visual Studio Build Tools | 2022, workload для C++ desktop development, MSVC и Windows SDK | Компиляция Rust/Tauri под Windows |
| WebView2 Runtime | актуальная версия | Отображение интерфейса Tauri |
| Свободное место | ориентировочно 6 ГБ | Python/Node-зависимости, браузер и модели; объём зависит от установки |

Для установки зависимостей требуется интернет. Голосовой ввод GigaSTT — отдельный компонент и в исходники проекта не включён. Облачные модели, облачное распознавание и некоторые веб-функции требуют интернета и соответствующих ключей.

## 2. Установка системных инструментов

Откройте PowerShell от имени обычного пользователя. После установки компонентов откройте новое окно PowerShell, чтобы обновились переменные среды.

Через `winget` можно установить базовые компоненты:

```powershell
winget install -e --id Python.Python.3.11
winget install -e --id OpenJS.NodeJS.LTS
winget install -e --id Rustlang.Rustup
```

Установите Visual Studio Build Tools 2022 с нагрузкой «Разработка классических приложений на C++» (MSVC и Windows SDK). В Windows 11 WebView2 обычно уже присутствует; при необходимости установите Microsoft Edge WebView2 Runtime.

Проверьте инструменты:

```powershell
py -3.11 --version
node -v
npm -v
rustc --version
cargo --version
```

У Rust должен быть MSVC toolchain. Если PowerShell блокирует ручной запуск `.ps1`, можно разрешить локальные скрипты для текущей учётной записи:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Это необязательно для файлов проекта: BAT-файлы запускают установочные скрипты с `-ExecutionPolicy Bypass`.

## 3. Подготовка папки

Скопируйте или распакуйте проект так, чтобы в корне рядом находились `README.md`, `INSTALL.md`, `Start-IDOS.bat`, `core`, `src`, `src-tauri` и `scripts`. Например:

```text
C:\IDOS-AI-AGENT
```

Для Windows-инструментов и Rust-сборки рекомендуется короткий путь без пробелов и нелатинских символов. Если Windows пометила файлы распакованного архива как загруженные из Интернета и блокирует скрипты, сначала убедитесь, что источник проекта вам доверен, затем снимите блокировку только с этой папки.

## 4. Установка зависимостей проекта

Из корневой папки выполните:

```powershell
cd C:\IDOS-AI-AGENT
powershell -ExecutionPolicy Bypass -File scripts\Setup.ps1
```

`Setup.ps1` создаёт `.venv` на Python 3.11, устанавливает пакеты из `requirements.txt`, устанавливает Chromium для Playwright, выполняет `npm install`, пытается скачать ffmpeg в `tools\ffmpeg\bin` и запускает самопроверку ядра. Необязательные модули могут отображаться как недоступные, если на компьютере нет внешней программы или разрешения.

Для ручной установки ffmpeg поместите `ffmpeg.exe` и `ffprobe.exe` в `tools\ffmpeg\bin`. ffmpeg используется, в частности, функциями записи экрана и обработки медиа.

## 5. Первый запуск

```powershell
Start-IDOS.bat
```

Скрипт запуска проверяет `.venv`, при наличии запускает GigaSTT, затем выполняет `npm run tauri dev`. При первом запуске Tauri компилирует Rust-оболочку; последующие старты обычно быстрее. Оболочка запускает Python-ядро `python -m core`. После запуска остров отображается поверх окон Windows, а значок приложения появляется в системном трее.

Не закрывайте окно консоли, из которого запущено приложение: при таком способе запуска закрытие процесса сборки/разработки завершает IDOS.

Самопроверку можно повторить через:

```powershell
Selftest-IDOS.bat
```

или в интерфейсе «Настройки → Самопроверка».

## 6. Модели и ключи

В интерфейсе откройте **Ctrl+Alt+A → «Ключи и модели»**. Добавьте ключ выбранного провайдера и выберите доступную модель. Настройка по умолчанию в проекте: `groq:openai/gpt-oss-120b`; фактическая доступность и лимиты зависят от провайдера и аккаунта. В исходниках предусмотрена поддержка нескольких облачных и локальных совместимых провайдеров, включая Groq, Gemini, OpenRouter, Cerebras, OpenAI, Anthropic, DeepSeek, xAI, Ollama и LM Studio.

Не помещайте рабочие ключи в исходники, README, тестовые фикстуры или публичные коммиты. Ключи, добавленные в интерфейсе, хранятся в `data\keys.json`; на Windows приложение пытается защищать их через DPAPI текущего пользователя. При переносе на другого пользователя или компьютер может потребоваться добавить ключ заново. Подробности и ограничения — в [SECURITY.md](SECURITY.md).

## 7. Голос

### Распознавание речи (STT)

Основной локальный вариант — GigaSTT. Если у вас есть доверенная сборка `gigastt.exe`, поместите её сюда:

```text
tools\gigastt\bin\gigastt.exe
```

При старте IDOS пытается запустить её на `127.0.0.1:9876`; модели хранятся в `models\gigastt`. При первом запуске модель может загружаться несколько минут. Для ручного старта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\Start-STT.ps1
```

Альтернатива — выбрать в настройках `voice.stt = groq`: аудио для распознавания будет отправляться облачному провайдеру, что требует сети и соответствующего API-ключа. Разрешите доступ к микрофону для классических приложений Windows и выберите нужное устройство ввода в настройках звука.

### Озвучивание (TTS)

В проекте реализован локальный Silero TTS. При первом синтезе приложение может скачать модель в `models\silero`; для работы нужны соответствующие Python-зависимости, включая `torch` и `scipy`. Можно выбрать голос, скорость и отключить озвучивание в настройках. Не рассчитывайте на облачное или системное резервное озвучивание: актуальная реализация движка — Silero или выключенный режим.

## 8. Основные сочетания клавиш

| Действие | Клавиши по умолчанию |
|---|---|
| Голосовой вопрос | `PageUp` |
| Командная строка | `Alt+Space` |
| Показать/раскрыть остров | `Ctrl+Alt+I` |
| Окно чата | `Ctrl+Alt+A` |
| Диктовка в активное окно | `Ctrl+Alt+D` |
| Буфер обмена | `Ctrl+Alt+V` |
| Скриншот области / экрана | `Ctrl+Alt+S` / `Ctrl+Alt+Shift+S` |
| OCR / QR / выбор цвета | `Ctrl+Alt+O` / `Ctrl+Alt+Q` / `Ctrl+Alt+C` |
| Запись экрана | `Ctrl+Alt+R` |
| Остановить агента | `Ctrl+Alt+X` |

Сочетания настраиваются в интерфейсе. Остановка прекращает текущий запуск агента, но не отменяет уже отправленное сообщение, изменение файла или иное внешнее действие.

## 9. Автономность и безопасное использование

В конфигурации по умолчанию `agent.autonomy` установлен в `full`. В этом режиме система не требует подтверждения перед большинством действий инструментов. Варианты `danger` и `all` включают запрос подтверждения соответственно для помеченных опасными действий или для всех действий, кроме чтения. Проверяйте текущую настройку в интерфейсе/`data\settings.json` и предпочитайте `danger` либо `all`, если хотите контролировать выполнение действий.

Инструмент `shell` может запускать произвольные команды PowerShell, cmd и Python с правами текущей учётной записи. Ctrl+Alt+X — кнопка остановки, а не песочница и не откат уже выполненного. Не подключайте неизвестные MCP-серверы и не поручайте агенту операции с важными аккаунтами без контроля.

## 10. Настройка острова

Параметры находятся в настройках интерфейса и в секции `island` файла настроек: тема, размер, персонаж, автоматическое скрытие, режим «сквозь», положение на мониторе, музыкальная пилюля, тексты песен, виджеты батареи/погоды и элементы панели. Доступность виджета погоды зависит от его настройки, местоположения/города и внешнего источника данных.

## 11. Обновление и резервное копирование

Перед обновлением закройте IDOS. Сделайте отдельную копию нужных пользовательских данных (`data`, а также нужных моделей и инструментов), затем обновите файлы исходников и повторите `scripts\Setup.ps1`. Не заменяйте и не удаляйте `data` без понимания его содержимого: там находятся настройки, база чатов/памяти, сценарии, заметки, захваченные данные и ключи. Папки `.venv` и `node_modules` можно пересоздать при проблемах с зависимостями, но сначала закройте приложение и убедитесь, что они не содержат пользовательских изменений.

Ключи DPAPI привязаны к контексту Windows, поэтому одной копии файла `keys.json` может быть недостаточно для переноса на другую машину или учётную запись. Создайте резервную копию, прежде чем менять системные файлы; не публикуйте её.

## 12. Разработка и сборка

```powershell
# Python-тесты
.venv\Scripts\python -m unittest discover -s tests

# Сборка интерфейса
npm run build

# Проверка Tauri/Rust
cd src-tauri
cargo check --locked
cd ..

# Сборка переносимой папки и ZIP (сначала запускаются тесты)
powershell -ExecutionPolicy Bypass -File scripts\Build-Release.ps1
```

Скрипт выпуска создаёт `release\IDOS-<версия>` и, если не указан `-NoZip`, ZIP-архив. Он не создаёт обычный самостоятельный установщик: для запуска переносимого комплекта всё ещё нужны папка с исходниками ядра и подготовленное окружение. После распаковки выполните `scripts\Setup.ps1`, затем `Start-IDOS.bat --release`.

CI описан в `.github/workflows/ci.yml`: Windows-запуск тестов Python, сборка Vite и `cargo check --locked`.

## 13. Частые проблемы

| Симптом | Что проверить |
|---|---|
| `py` не найден или выбрана неверная версия | Установите Python 3.11 вместе с Python Launcher; откройте новое PowerShell-окно. |
| Ошибки `link.exe`, `MSVC` при Rust-сборке | Установлены ли Visual Studio Build Tools 2022, MSVC и Windows SDK. |
| Окно не появляется или ошибка WebView2 | Установлен ли WebView2 Runtime; проверьте вывод консоли и `logs`. |
| Порт 5173 занят | Закройте другой процесс Vite/IDOS, который использует этот порт. |
| Остров показывает, что ядро не готово | Проверьте `logs` и свежесть `data\runtime\core.json`; запустите самопроверку. |
| Голосовой ввод не работает | Проверьте разрешение микрофона, выбранное устройство, наличие `gigastt.exe` и порт 9876 либо настройку облачного STT. |
| Нет голосового ответа | Проверьте, что TTS не отключён, установлены `torch` и `scipy`, а модель Silero доступна. |
| Модель возвращает ошибку или лимит | Проверьте ключ, выбранную модель, доступность провайдера, баланс и лимиты аккаунта. |
| Функция недоступна | Проверьте самопроверку, нужную внешнюю программу, разрешения Windows и журнал `logs`. |

При обращении за помощью приложите точный текст ошибки и релевантные последние строки логов после проверки, что в них нет ключей, личных данных и приватного содержимого. Не отправляйте файл `data\keys.json`.
