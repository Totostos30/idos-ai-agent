# Установка Эйдоса (IDOS) 2.5.6 на Windows 11

Инструкция рассчитана на чистую виртуальную машину с Windows 11. Если у вас уже стоит старая версия (IDIOS), прочитайте сначала раздел 9.

Папка проекта в инструкции: `C:\IDOS-AI-AGENT`. Можно выбрать любую другую, но **без пробелов и русских букв в пути**.

Про время: первая установка занимает 30–60 минут, примерно половина уходит на скачивание и первую сборку Tauri.

---

## 1. Что понадобится

| Что | Версия | Зачем |
|---|---|---|
| Windows 11 | 22H2 или новее | система |
| Python | **3.11** (именно 3.11) | ядро агента |
| Node.js | 20 или новее (LTS) | интерфейс, сборка |
| Rust | stable через rustup | оболочка Tauri (окно-остров) |
| Visual Studio Build Tools | 2022, «Разработка классических приложений на C++» | компилятор для Rust |
| WebView2 Runtime | любая | движок окна (в Windows 11 обычно уже есть) |
| Ключ Groq | бесплатный, можно несколько | модель по умолчанию |
| Свободное место | ~6 ГБ | пакеты, браузер агента, модели голоса |

Нужен интернет: установщик скачивает пакеты Python, npm, Chromium для агента и ffmpeg.

---

## 2. Установка инструментов (один раз)

Всё ниже делается в **PowerShell от имени обычного пользователя**, если не сказано иначе. После каждой установки **закройте и заново откройте PowerShell**, чтобы обновились пути.

### 2.1. Python 3.11

Вариант через winget:

```powershell
winget install -e --id Python.Python.3.11
```

Или вручную с python.org (Windows installer 64-bit). В установщике обязательно отметьте **«Add python.exe to PATH»** и оставьте **«py launcher»**.

Проверка:

```powershell
py -3.11 --version
```

Должно быть `Python 3.11.x`.

### 2.2. Node.js

```powershell
winget install -e --id OpenJS.NodeJS.LTS
```

Проверка: `node -v` и `npm -v`.

### 2.3. Visual Studio Build Tools (C++)

```powershell
winget install -e --id Microsoft.VisualStudio.2022.BuildTools --override "--wait --passive --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
```

Если ставите вручную: в Visual Studio Installer выберите рабочую нагрузку **«Разработка классических приложений на C++»** (MSVC и Windows 11 SDK). Это около 5 ГБ.

### 2.4. Rust

```powershell
winget install -e --id Rustlang.Rustup
```

После установки откройте новое окно PowerShell и выполните:

```powershell
rustup default stable-msvc
rustc --version
cargo --version
```

### 2.5. WebView2

В Windows 11 он почти всегда уже установлен. Если окно Эйдоса потом не откроется с ошибкой про WebView2:

```powershell
winget install -e --id Microsoft.EdgeWebView2Runtime
```

### 2.6. Разрешить запуск скриптов (рекомендуется)

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

На вопрос ответьте `Y`. Bat-файлы проекта и так запускают скрипты с `-ExecutionPolicy Bypass`, это нужно только для ручного запуска `.ps1`.

## 3. Распаковка проекта

1. Распакуйте `idos-v2.1.zip`. Внутри лежит папка `idos`.
2. Переименуйте или переместите её так, чтобы получилось `C:\IDOS-AI-AGENT`, и **прямо в ней** лежали `README.md`, `INSTALL.md`, `Start-IDOS.bat`, папки `core`, `src`, `src-tauri`, `scripts`.
3. Если Windows пометил архив как скачанный из интернета, скрипты могут блокироваться. Снимите блокировку:

```powershell
Get-ChildItem C:\IDOS-AI-AGENT -Recurse | Unblock-File
```

---

## 4. Автоматическая установка зависимостей

```powershell
cd C:\IDOS-AI-AGENT
powershell -ExecutionPolicy Bypass -File scripts\Setup.ps1
```

Скрипт по шагам:

1. **Python venv**: создаёт `.venv` на Python 3.11 и ставит пакеты из `requirements.txt`. Среди них PyTorch для CPU (для голоса Silero), это самая долгая часть (~1 ГБ).
2. **Playwright Chromium**: отдельный браузер, которым агент ходит по сайтам.
3. **npm install**: Tauri CLI, Vite и API для интерфейса.
4. **ffmpeg**: скачивает в `tools\ffmpeg\bin` (нужен для записи экрана и GIF).
5. **Самопроверка**: выводит список того, что работает, а что нет.

В конце должно появиться зелёное **«Готово. Запуск: Start-IDOS.bat»**.

Нормально, если самопроверка ругается на необязательные вещи: Tesseract, GigaSTT, ключи (их добавим позже). Ядро работает и без них: отсутствующая функция просто выключается.

**Если ffmpeg не скачался**: скачайте сборку `ffmpeg-release-essentials.zip` с gyan.dev и положите `ffmpeg.exe` и `ffprobe.exe` в `C:\IDOS-AI-AGENT\tools\ffmpeg\bin`.

## 5. Распознавание речи (GigaSTT)

Эйдос слушает через локальный GigaSTT на порту 9876. Он работает на CPU, без интернета.

- **Если у вас осталась старая установка IDIOS**: скопируйте оттуда две папки в новую:
  - `tools\gigastt` → `C:\IDOS-AI-AGENT\tools\gigastt` (там должен быть `bin\gigastt.exe`);
  - `models\gigastt` → `C:\IDOS-AI-AGENT\models\gigastt`.
- **Если ставите с нуля**: положите `gigastt.exe` в `C:\IDOS-AI-AGENT\tools\gigastt\bin`. При первом запуске он сам скачает модель в `models\gigastt`, это может занять несколько минут.

GigaSTT запускается автоматически из `Start-IDOS.bat` (в свёрнутом окне), если файл найден и порт 9876 свободен. Запустить вручную:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\Start-STT.ps1
```

Запасной вариант без GigaSTT: в «Настройки» поставьте `voice.stt` = `groq`. Тогда речь распознаёт Whisper через ваши ключи Groq (нужен интернет, тратит лимиты).

## 6. Первый запуск

Дважды щёлкните **`Start-IDOS.bat`** или выполните:

```powershell
cd C:\IDOS-AI-AGENT
.\Start-IDOS.bat
```

Что происходит:

1. Запускается GigaSTT (если есть).
2. `npm run tauri dev` поднимает интерфейс и **компилирует оболочку на Rust**. Первая сборка занимает **5–15 минут**, следующие запуски проходят за секунды.
3. Оболочка сама запускает Python-ядро.
4. Вверху экрана появляется чёрная капсула-остров, в трее появляется значок.

Окно консоли не закрывайте: это и есть запущенное приложение. Закрытие консоли закрывает Эйдос.

**Если сборка Rust упала с ошибкой**: прокрутите консоль к первой строке `error[...]`, скопируйте её вместе с 10–20 строками ниже и пришлите мне. Оболочку на Rust я не мог скомпилировать заранее, так что на первой сборке возможны мелкие ошибки.

## 7. Настройка после запуска

### 7.1. Ключи Groq

1. Откройте окно Эйдоса: **Ctrl+Alt+A** или щелчок по значку в трее.
2. Вкладка **«Ключи и модели»**.
3. Провайдер **Groq**. Вставьте ключи, **по одному на строку** (можно сразу 5–10), нажмите «Добавить».
4. Нажмите «Проверить» у ключа: должен появиться зелёный статус.

Ключи создаются на console.groq.com → API Keys. Важно: лимиты Groq считаются **на аккаунт**, а не на ключ. Несколько ключей из одного аккаунта лимит не увеличат, нужны ключи из разных аккаунтов. Эйдос сам переключается на следующий ключ, когда текущий подходит к лимиту.

Модель по умолчанию: `groq:openai/gpt-oss-120b`. Здесь же можно добавить ключи Gemini или OpenRouter как запасных провайдеров.

Ключи сохраняются в `data\keys.json` зашифрованными средствами Windows (DPAPI) и привязаны к
учётной записи: при переносе папки на другой компьютер их нужно добавить заново. Старый файл с
ключами открытым текстом шифруется автоматически при первом запуске.

### 7.2. Микрофон и разрешения Windows

- «Параметры → Конфиденциальность и защита → Микрофон»: включите доступ для классических приложений.
- На виртуальной машине пробросьте микрофон хоста (в VMware/VirtualBox/Hyper-V это отдельная настройка «Аудиовход»).

### 7.3. Голос ответов (Silero)

Ничего ставить не нужно. При первом ответе голосом Эйдос сам скачает модель Silero (`models\silero\v5_ru.pt`, ~100 МБ), поэтому первый голосовой ответ будет с задержкой. Если Silero не загрузится, используется запасной голос edge-tts (нужен интернет).

### 7.4. Внешний вид острова

«Настройки» → раздел `island`:

| Параметр | Значения |
|---|---|
| `character` | `liquid` (по умолчанию), `eyes`, `pixel`, `spark`, `cube`, `dot` |
| `music_pill` | `normal`, `wide`, `mini` |
| `auto_hide` | прятать остров за край экрана |
| `through_mode` | клики проходят сквозь остров |
| `scale` | размер, 0.8–2.0 |
| `theme` | `dark` или `light` |
| `lyrics`, `eq_edge` | строка песни и жидкий край под музыку |

### 7.5. Самопроверка

`Selftest-IDOS.bat` или «Настройки → Самопроверка». Покажет, что из функций доступно и что доустановить.

## 8. Как пользоваться (коротко)

| Действие | Клавиши |
|---|---|
| Голосовой вопрос | PageUp |
| Командная строка | Alt+Space |
| Показать/раскрыть остров | Ctrl+Alt+I |
| Окно чата | Ctrl+Alt+A |
| Диктовка в любое окно | Ctrl+Alt+D |
| Буфер обмена | Ctrl+Alt+V |
| Скриншот области / экрана | Ctrl+Alt+S / Ctrl+Alt+Shift+S |
| OCR / QR / пипетка | Ctrl+Alt+O / Q / C |
| Запись экрана | Ctrl+Alt+R |
| **Аварийная остановка агента** | **Ctrl+Alt+X** |

Голосом: «Эйдос, открой блокнот и напиши список покупок», «найди в интернете…», «переключись на …» (смена модели).

Агент работает с **полной автономией**: сам кликает, печатает и запускает программы. Держите под рукой **Ctrl+Alt+X**.

## 9. Если стоит старая версия (IDIOS)

1. Закройте старое приложение (трей → Выход).
2. Ставьте новую версию **в новую папку** `C:\IDOS-AI-AGENT`, старую не удаляйте, пока всё не заработает.
3. Скопируйте из старой папки:
   - `tools\gigastt` и `models\gigastt` (распознавание речи);
   - при желании `tools\ffmpeg`.
4. Старые `.venv`, `node_modules` и `data` **не копируйте**: форматы изменились, установщик создаст всё заново.
5. Ключи Groq добавьте заново через «Ключи и модели».

---

## 10. Обновление до следующих версий

1. Закройте Эйдос.
2. Распакуйте новую версию поверх `C:\IDOS-AI-AGENT` с заменой файлов. Папки `data`, `models`, `tools`, `.venv`, `node_modules` в архив не входят и останутся на месте, с ними сохранятся ключи, чаты, память и настройки.
3. Снова запустите `scripts\Setup.ps1` (доставит новые пакеты, займёт пару минут).
4. `Start-IDOS.bat`.

## 11. Сборка релиза (по желанию)

Когда всё работает в режиме разработки, соберите переносимую папку и архив:

```powershell
cd C:\IDOS-AI-AGENT
powershell -ExecutionPolicy Bypass -File scripts\Build-Release.ps1
```

Скрипт прогоняет тесты, собирает интерфейс (`npm run build`), компилирует `idos.exe`
(`npm run tauri build`) и складывает готовый комплект в `release\IDOS-<версия>` и
`release\IDOS-<версия>.zip`. В архив не попадают `.venv`, `node_modules`, `data`, `logs`,
`models` и `tools`.

Запуск собранной версии: распакуйте, один раз выполните `scripts\Setup.ps1`, затем
`Start-IDOS.bat --release` (или `src-tauri\target\release\idos.exe`). Папку проекта
удалять нельзя: Python-ядро, навыки и модели берутся из неё.

> Установщик NSIS сознательно не включён (`bundle.active: false`). Приложению нужны
> Python-ядро и `.venv` рядом с exe; «обычный» установщик без них даёт неработающее
> приложение. Если понадобится настоящий установщик, сначала нужно встраивать Python
> и зависимости — это отдельная задача, а не переключение флага.

## 12. Частые проблемы

| Симптом | Что делать |
|---|---|
| `py` не найден или не та версия | Переустановите Python 3.11 с галочкой «py launcher», откройте новое окно PowerShell. |
| Кракозябры или `ParserError` в PowerShell | Запускайте через `powershell -ExecutionPolicy Bypass -File ...`, не копируйте текст скриптов вручную. Файлы `.ps1` сохранены в UTF-8 с BOM. |
| `link.exe not found`, `MSVC` в ошибке Rust | Не установлены Build Tools C++ (п. 2.3). |
| Сборка Rust падает с `error[E...]` | Пришлите мне первую ошибку целиком. |
| Окно не появляется, ошибка WebView2 | Установите WebView2 (п. 2.5). |
| `Port 5173 is already in use` | Закройте другое окно консоли Эйдоса или перезагрузитесь. |
| Остров есть, но «ядро…» не пропадает | Посмотрите `logs\` и `data\runtime\core.json`; запустите `Selftest-IDOS.bat`. |
| Groq отвечает 403 `error code: 1010` | Это защита Cloudflare. Эйдос уже отправляет свой User-Agent; если ошибка осталась, проверьте VPN или прокси и пришлите лог. |
| Groq 429 (лимит) на всех ключах | Ключи из одного аккаунта делят лимит, добавьте ключи из других аккаунтов или запасного провайдера. |
| Не распознаётся речь | Проверьте, что GigaSTT запущен (свёрнутое окно, порт 9876), микрофон разрешён и выбран в `audio.input_device`. |
| Нет голоса в ответах | Первый ответ ждёт загрузки Silero; проверьте интернет при первом запуске. |
| Не работает Alt+Shift внутри окна Эйдоса | Известная проблема, используйте Win+Пробел. |
| SmartScreen или антивирус блокирует | Это неподписанная сборка, разрешите запуск на виртуальной машине. |

Если что-то пошло не так, пришлите: скриншот или текст ошибки из консоли, вывод `Selftest-IDOS.bat` и последние строки файлов из `logs\`.
