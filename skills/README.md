# Встроенные навыки

Markdown-плейбуки, которые агент видит в системном промпте и загружает по имени
инструментом `skill` (`load`/`save`).

- Файл: `имя.md`, имя — латиница/цифры/дефис.
- Начало файла — front matter:

```markdown
---
name: windows-apps
title: Программы и окна Windows
description: Одна строка для списка навыков
---
```

- `data/skills/*.md` перекрывает встроенный навык с тем же именем.
- `README.md` и `AGENTS.md` загрузчик пропускает.
- Правь встроенные навыки здесь; пользовательские создавай через интерфейс или
  `skill save` — они попадут в `data/skills` и не потеряются при обновлении.
