# Навыки IDOS

Навыки — Markdown-плейбуки для типовых задач. Агент видит краткие описания навыков в системном контексте и может загрузить полный текст по имени инструментом `skill` (`load`). Пользовательские навыки создаются через интерфейс или инструмент `skill save`.

## Формат встроенного навыка

Встроенные плейбуки хранятся в `skills/*.md`. Имя файла — латиница, цифры и дефисы. В начале файла укажите YAML front matter:

```markdown
---
name: windows-apps
title: Программы и окна Windows
description: Краткое описание для списка навыков
---

# Программы и окна Windows

Инструкции для агента…
```

Файлы `README.md` и `AGENTS.md` не загружаются как навыки. Пользовательские навыки хранятся в `data/skills/*.md` и перекрывают встроенный навык с таким же именем. Чтобы сохранить пользовательский рецепт так, чтобы он пережил обновление исходников, используйте интерфейс или `skill save`, а не редактируйте папку `data/` как часть исходников.

Навык — инструкция для модели, а не отдельный механизм безопасности: его текст не ограничивает права инструментов и не заменяет политику подтверждений `agent.autonomy`. См. [общую документацию безопасности](../SECURITY.md).

## Встроенные плейбуки

- `windows-apps.md` — запуск приложений и работа с окнами.
- `web-research.md` — поиск и проверка веб-источников.
- `files-cleanup.md` — безопасный разбор и удаление файлов.
