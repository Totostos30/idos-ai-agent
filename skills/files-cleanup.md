# Безопасная уборка файлов

Цель — освободить место, не потеряв нужные данные. Удаление — последний шаг, а не первый.

## Порядок действий

1. **Оценить ситуацию.** Используй `system.info` для дисков и свободного места; `system.processes` — для списка процессов, если компьютер тормозит.
2. **Найти кандидатов.** `files.search` по имени/маске и каталогу (`downloads`, `desktop`, `documents` или разрешённый абсолютный путь). `files.info` покажет сведения об объекте. Поиск содержимого поддерживается только в части текстовых файлов.
3. **Показать список.** Для каждого кандидата перечисли путь, размер, дату изменения и причину, по которой его можно удалить. Не удаляй по одному лишь расширению или возрасту.
4. **Получить подтверждение на точное удаление.** Назови конкретные файлы/папки и ожидаемые последствия, дождись явного согласия. Не делай это через `shell`, если хватает `files`.
5. **Удалить через `files.delete`.** По текущей реализации инструмент перемещает объект в собственную резервную копию, а `files.restore` может вернуть её. Проверь ответ и то, что резервная копия создана; при ошибке остановись, не повторяй удаление вслепую.
6. **Проверить итог.** Повтори `files.info`/`system.info` и отчитайся. Не очищай корзину Windows, если пользователь отдельно не подтвердил это конкретное действие: оно помечено как опасное и может уничтожить возможность восстановления.

## Правила

- Никогда не удаляй целиком системные каталоги Windows, Program Files, ProgramData или AppData.
- Не изменяй и не удаляй `data/`, `logs/`, `.env` и `data/keys.json` проекта IDOS через задачи очистки.
- Не удаляй каталоги проектов с `.git`; предложи архивировать их после согласования.
- Личные документы, фотографии, профили браузера, базы данных и резервные копии нельзя удалять без явного согласия пользователя.
- Если цель или владелец файла неясны, не удаляй его: запроси уточнение или предложи переместить в отдельную папку.
- `files.delete` обычно создаёт резервную копию, но это не гарантия при отказе диска, нехватке места или ошибках доступа. Проверь результат и не обещай восстановление до проверки.
- Режим `agent.autonomy=full` может отключить системный запрос подтверждения. Соблюдай требование подтверждения из этого навыка самостоятельно; см. `SECURITY.md`.
