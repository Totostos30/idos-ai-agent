# Программы и окна Windows

Цель: выполнить задачу в программе так, как это сделал бы человек за компьютером.

## Порядок действий

1. **Найти и запустить.** `apps search` с названием («телеграм», «вс код», «excel») → `apps launch`.
   `launch` возвращает номер окна — сохрани его.
   Если путь известен, `apps open` откроет файл/папку/ссылку программой по умолчанию.
2. **Понять экран.** `windows list` — все окна; `windows focus` — вывести нужное вперёд.
   `windows snapshot` — элементы с номерами `[ref]`; `windows read` — весь текст окна.
   `windows find` — сразу найти элемент по подписи.
3. **Действовать по ref, а не по координатам.** `windows click`, `type`, `toggle`,
   `select`, `expand`, `get`. Координаты — только через `computer click (x, y)` или
   `computer find (target)`, когда у элемента нет доступного имени.
4. **Проверить результат.** После каждого действия — `windows snapshot` или чтение
   изменившегося фрагмента. Не повторяй действие вслепую.
5. **Закрыть лишнее.** `apps close` — мягко закрыть окна; `apps kill` — только если
   программа зависла, и только с подтверждением пользователя, если там несохранённые данные.

## Правила

- Сначала `windows` (доступность и точность), `computer` — запасной вариант.
- Не вводи пароли, коды из СМС и платёжные данные без прямой просьбы пользователя.
- Перед необратимым действием в интерфейсе (удаление, отправка, покупка) назови шаг и
  дождись подтверждения, если пользователь не просил выполнить всё сразу.
- Каждый шаг — короткий и проверяемый. Если интерфейс не отвечает 2–3 раза подряд,
  остановись и объясни, что видишь на экране.
