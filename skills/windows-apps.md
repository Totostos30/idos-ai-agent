# Программы и окна Windows

Цель — выполнить пользовательскую задачу в программе и проверить результат. Эти инструменты управляют настоящим рабочим столом Windows от имени текущей учётной записи; действуй внимательно.

## Порядок действий

1. **Найти и запустить.** Используй `apps.search` для поиска программы, затем `apps.launch`. Запуск вернёт сведения о новом или уже открытом окне. Для файла, папки или ссылки используй `apps.open`.
2. **Понять состояние.** `apps.list` перечисляет работающие программы и окна. `windows.list` показывает окна; `windows.focus` выводит выбранное окно вперёд. `windows.snapshot` даёт доступные элементы с краткими ссылками `[ref]`; `windows.read` читает текст окна; `windows.find` ищет элемент по подписи.
3. **Действовать по доступной ссылке элемента.** Предпочитай `windows.click`, `windows.type`, `windows.toggle`, `windows.select`, `windows.expand` и `windows.get`, если элемент распознаётся UI Automation. Для сложных или недоступных интерфейсов используй `computer.screenshot`, `computer.ocr`, `computer.find` и затем действие по координатам.
4. **Проверить результат.** После ввода или действия перечитай изменённое состояние окна либо сделай новый snapshot. Не повторяй действие только потому, что интерфейс ответил медленно: сначала проверь, не произошло ли оно.
5. **Закрывать и завершать процессы осознанно.** `apps.close` просит программу закрыть окно обычным способом. `apps.kill` принудительно завершает процесс и может потерять несохранённые данные; перед ним объясни последствия и получи явное согласие, если пользователь прямо не просил завершить именно этот процесс.

## Правила

- Начинай с `windows` для точного чтения контролов; `computer` используй, когда UI Automation не даёт нужного элемента.
- Не вводи пароли, одноразовые коды и платёжные данные. Если задача действительно требует их ввода, остановись и попроси пользователя выполнить этот шаг самостоятельно.
- Перед отправкой, покупкой, удалением, публикацией или другим внешним/необратимым действием остановись и получи явное подтверждение, если пользователь не одобрил именно это действие и его параметры.
- Настройка `agent.autonomy=full` может отключать подтверждения на уровне диспетчера инструментов. Не полагайся только на системное всплывающее окно: следуй правилам этого навыка. Подробнее — `SECURITY.md`.
- Делай короткие проверяемые шаги. Если интерфейс не отвечает или неоднозначен, остановись и опиши пользователю наблюдаемое состояние.
