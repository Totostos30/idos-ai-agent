# Гайдбук дизайна Эйдоса

Версия 1.0 · Ветка `re-design-ui` · Обязателен для всех изменений интерфейса.
Коротко: **жидкая чёрная капсула с фирменным 4-цветным свечением; всё остальное — тихая система, которая её не перебивает.**

---

## 1. Характер продукта (для кого это)

Эйдос — настольный голосовой агент для Windows. Интерфейс: остров-капсула сверху экрана (всегда виден, почти не занимает места) и главное окно (диалоги, настройки, сценарии).

Пять принципов:

1. **Капсула — единственная героиня.** Декор только там, где он передаёт состояние (музыка, запись, работа агента).
2. **Состояние видно без чтения.** Цвет орба/микрофона/шага важнее текста; но текст-подпись всегда есть.
3. **Система незаметна.** Шкалы, сетка, токены — чтобы новые экраны не проектировали «с нуля».
4. **Обе темы равноправны.** Любой новый компонент сразу верифицируется в dark и light.
5. **Никаких AI-штампов**: эмодзи-иконки, случайные градиенты, глоу ради глоу, копирайт-паразиты («мощный», «лёгкий», «без усилий»).

## 2. Цвет

### 2.1 Слои

Работаем **только** с семантическими токенами. Сырые hex разрешены в единственном файле `src/tokens.css` и в JS-константах бренда.

| Токен | Dark | Light | Назначение |
|---|---|---|---|
| `--surface-0` | `#000` | `#fbfbfd` | фон окна/острова |
| `--surface-1` | `#111114` | `#f4f4f6` | карточки, боксы, элементы списков |
| `--surface-2` | `#141417` | `#f3f3f5` | композер, пузыри диалога, панели |
| `--surface-3` | `#1b1b20` | `#ffffff` | тосты, нативные списки, верхняя тень стека |
| `--text-1` | `#f5f5f7` | `#111114` | основной текст |
| `--text-2` (`--mut`) | `#9a9aa2` | `#6b6b75` | вторичный текст, подписи |
| `--border-1` | `rgba(255,255,255,.09)` | `rgba(0,0,0,.08)` | границы, внутренние обводки |
| `--fill-1` | `rgba(255,255,255,.07)` | `rgba(0,0,0,.05)` | hover-подложки, поля |
| `--fill-2` | `rgba(255,255,255,.13)` | `rgba(0,0,0,.10)` | активные подложки, чипы |
| `--accent` | `#7c8cff` | `#5b6ee0`¹ | акцент действий, ссылки, фокус |
| `--accent-contrast` | `#000` | `#fff` | текст НА акценте |
| `--ok` / `--warn` / `--err` | `#35d07f` / `#ffb547` / `#ff5a5f` | `#1f9d5e`¹ / `#b07016`¹ / `#e03e43`¹ | состояния |
| `--brand-1..4` | `#7c8cff #b46cff #4fd1ff #e07cff` | — те же | **не темизируются** — идентичность |

¹ пример адаптированного значения; точные light-значения фиксируются в tokens.css после проверки контраста.

### 2.2 Правила

- Текст на поверхности: контраст ≥4.5:1 (≥11px), крупный заголовок ≥3:1. Проверять **в обеих темах**.
- Вторичный текст `--text-2` не затемнять/осветлять локальными opacity — нужен контраст, меняйте токен или размер.
- Полупрозрачный акцент — только через `color-mix(in srgb, var(--accent) N%, transparent)`, N ∈ {8, 14, 25, 45}.
- Состояний пять: ok / warn / err / disabled (opacity .35) / selected (`--fill-2` + inset-обводка акцентом 1.5px). Смешивать запрещено.
- Фирменный градиент (`--brand-1→2→3`) — только: логотип, орб-персонаж, кольцо распознавания, точка выбора модели. Больше нигде.

## 3. Иконки

- Один набор: monoline SVG, `stroke: currentColor`, толщина **1.7px**, сетка **16px** (внутри острова и кнопок) и **24px** (страницы), `fill="none"`, скругления концов `round`.
- Компонент `Icon(name, size)` — единственный способ вставить иконку; прямые `<img>`/символы запрещены.
- **Эмодзи запрещены** в кнопках, вкладках, заголовках, списках, тостах — везде, где это «иконка». Эмодзи допустим только как *контент* (текст сообщения).
- Иконка всегда с подписью (`title`) либо рядом с текстом; важные действия не бывают icon-only.
- Состояния шагов: running = вращающийся контур, ok = галка, err = крест, denied = перечёркнутый круг — те же SVG, не символы ◌✓✕.
- Минимальный набор для старта: chat, memory, key, tools, scenario, settings, mic, mic-off, stop, play, pause, next, prev, clock, bell, copy, paste, delete, edit, close, chevron-up/down/left/right, search, external, check, alert, dot, sun, moon, theme-auto.

## 4. Типографика

Шрифт: `"Segoe UI Variable Text", "Segoe UI", system-ui, sans-serif`. Моно: `"Cascadia Mono", Consolas, monospace` (hash, коды, тайминги).

Шкала (6 размеров + межстрочные):

| Токен | Размер | LH | Где |
|---|---|---|---|
| `--t-display` | 24px/600 | 1.2 | h1 страниц |
| `--t-title` | 17px/600 | 1.3 | h2 секций |
| `--t-heading` | 15px/600 | 1.35 | h3 боксов, имена чатов |
| `--t-body` | 14px/400 | 1.45 | основной текст, поля (главное окно) |
| `--t-body-s` | 13px/400 | 1.4 | остров, компактные списки |
| `--t-caption` | 12px/400 | 1.35 | подписи, meta; **минимальный размер в продукте** |

Правила:
- 10.5–11.5px не используются вовсе; 12px — минимум (`.act`-чипы и подобные поднимаются до 12).
- Числа, которые меняются (таймеры, счётчики, проценты, score, размеры) — `font-variant-numeric: tabular-nums`.
- Кавычки «ёлочки», многоточие `…`, длинное тире `—` в копирайте интерфейса.
- Заголовок: воздух **над** ≥ воздуху **под**.

## 5. Отступы и сетка

Сетка 4px. Шкала: `--s-1: 4px, --s-2: 8px, --s-3: 12px, --s-4: 16px, --s-5: 20px, --s-6: 24px, --s-8: 32px, --s-10: 40px`.

- Между независимыми боксами: `--s-4`; внутри бокса между секциями: `--s-3`; строка-потомок: `--s-2`; иконка↔текст: `--s-2`.
- Поля страниц: 22–28px горизонталь не трогаем (уже), вертикальный ритм кратен 4.
- Списки одного типа — один и тот же вертикальный ритм (не 2px / 3px / 6px в соседних списках).

---

## 6. Радиусы и тени

Радиусы — шкала из 5: `--r-s: 8px` (чипы, теги), `--r-m: 12px` (поля, пункты списков), `--r-l: 16px` (карточки, боксы), `--r-xl: 22px` (капсула, крупные карточки уведомлений), `--r-round: 999px` (пилюли). Всё прочее мапится: 9→`--r-s`, 14/18→`--r-l`, 20/24/26/28→`--r-xl` (по визуальной массе).

Тени — две глубины + glow-токен:
- `--shadow-1`: `0 10px 32px rgba(0,0,0,.35)` — остров, карточки уведомлений;
- `--shadow-2`: `0 18px 50px rgba(0,0,0,.45)` — модалки, всплывающие панели;
- `--glow-accent`: `0 0 24px color-mix(in srgb, var(--accent) 18%, transparent)` — только фокус композера и edge-glow музыки.
- Тень обязана иметь смещение по Y; чистые цветные ореолы вокруг элемента — только через `--glow-accent` и только для «живых» состояний.

---

## 7. Движение

- Кривые: `--spring: cubic-bezier(.34,1.36,.5,1)` — раскрытие капсулы, появление карточек; `--ease: cubic-bezier(.2,.8,.2,1)` — всё остальное.
- Длительности: микро (hover/фокус) 0.15–0.2s; раскрытие капсулы 0.45–0.5s; вход карточек 0.3–0.5s.
- Анимируются только `transform`, `opacity`, `clip-path`, `width/height` у капсулы. `transition: all` запрещён.
- Signature-анимации — неприкосновенны: gwaves микрофона, blob орба, «капание» карточек, edge-glow по басам, «пропевание» строки лирики.
- `prefers-reduced-motion`: гасить **декоративное** (blob, лирика-анимация, marquee), **сохранять смысл** — вместо пульсаций оставить статичную заливку/цвет состояния (run-running → постоянная акцентная обводка, «слушаю» → статичная волна).

## 8. Компоненты

**Кнопки** — 4 варианта: `.btn.primary` (заливка `--text-1`, текст `--bg` — «главное действие одно на экран»), `.btn` (заливка `--fill-2`), `.btn.ghost` (только inset-обводка `--border-1`), `.btn.danger` (`--err`, белый текст). Высоты: 26px (остров), 32px (компакт), 36px (страницы). Состояния: hover — brightness 1.25; disabled — opacity .35; focus-visible — outline 2px `--accent`, offset 2px.

**Поля** `.field` — `--fill-1`, radius `--r-m`, фокус: обводка `color-mix(accent 70%)` + фон `--fill-2`. Placeholder = `--text-2`. Placeholder-as-label запрещён: у всех полей видимая подпись слева (`.setrow .k`) или сверху.

**Карточки** — `--surface-1` + inset-обводка `--border-1`, radius `--r-l`, паддинги `12px 14px` (не «карточка в карточке»: внутри бокса дочерние блоки разделяются `--border-1`, а не новой заливкой).

**Тосты/уведомления** — `--surface-3`, radius `--r-xl`, `--shadow-1`; статус — inset-обводкой цвета состояния (не фоновой заливкой всей плашки).

**Чипы/теги** — radius `--r-s`/round, 12px, `--fill-1`; статусы — цвет текста + подложка `color-mix(state 14%)`.

**Остров** — ширины режимов фиксированы (200/210/260/320/380/400/440/460/560/620px), `--r-xl` сверху 12px у «висящих» режимов; всё внутреннее — 13px/base, компактные высоты 24–26px.

**Сценарии** — рёбра/порты: `--accent`; ветки yes/no/fail: `--ok/--warn/--err`; сетка холста точками `--border-1`; узел = `--surface-1`, selection = акцентная обводка 1.5px + `--glow-accent`.

## 9. Темы

- Пользователь выбирает: Системная / Тёмная / Светлая / <кастом> + отдельно акцент.
- Новая тема = только semantic-слой (~18 переменных), поверх базового dark/light; primitive и бренд не редактируются.
- Контраст-гейт при сохранении кастома: пары текст/поверхность <4.5:1 не сохраняются.
- Компоненты **никогда** не пишут `@media (prefers-color-scheme)` и не проверяют тему сами — только токены. JS читает тему в одном месте: `src/theme.js`.

## 10. Копирайт интерфейса (анти-slop)

- Пишем по-русски, конкретно, без превосходных степеней и восклицаний: «Запись сохранена», не «Успешно записано!».
- Кнопки — глагол: «Записать вариацию», «Обновить список»; не «ОК», не «Продолжить» без смысла.
- Пустые состояния помогают начать: «Пока нет эталонов — запишите 3–5 вариаций» (не «Здесь пока пусто»).
- Чипы приветствия — живые сценарии пользы («Собери сводку по моим заметкам»), не функции системы («Включи тёмную тему»).
- Ошибки: что случилось + что делать. «Нет доступа к микрофону — разрешите доступ в настройках Windows».
- Числа и единицы по ГОСТ-стилю: «2,5 с», «3 из 15 коммитов».

## 11. Чек-лист перед коммитом UI-изменения

1. Ноль сырых hex вне `src/tokens.css` (grep-линт проходит).
2. Ноль эмодзи-иконок; все иконки через `Icon()`, у icon-only кнопок есть `title`.
3. Новые размеры/отступы/радиусы — из шкал §4–6.
4. Проверено в **dark и light**, в **острове и главном окне** (и в select, если трогали выделение).
5. Все пять состояний у затронутых компонентов: hover, focus-visible, disabled, selected, error.
6. Числа с `tabular-nums`; минимум текста — 12px.
7. `npm run build` зелёный; в Tauri-окнах нет вспышки не той темы при старте.
8. `prefers-reduced-motion` сохраняет смысловые индикаторы.
9. Скриншот изменения приложен к PR/сообщению коммита (или описана причина, почему нельзя).
