## 2. Что работает отлично (сохранить)

1. **Знак Νοῦс как живой индикатор** — лучшее решение редизайна: состояние читается по темпу без чтения текста, ядро-точка даёт «глаз» интерфейсу. Это тот визуальный крючок, который запоминают.
2. **Γλῶττα-слой** — сдержан и осмыслен: бейдж-точка + слово + перевод в title. Работает как фирменная подпись, не как шум. Проверка «убери греческий — интерфейс понятен» проходит на всех экранах.
3. **Токен-система** — светлая тема из одних переопределений, кастомные темы с контраст-гейтом: профессиональная архитектура цвета, редко встречается в десктоп-приложениях.
4. **Сегмент-контрол темы** — мгновенное применение без перезапуска (проверено кликом), тактильный отклик переключения.
5. **Пустые состояния** — «Скиллов пока нет — агент создаёт их сам…»: объясняют, а не констатируют.

## 3. Удобство использования (UX) — находки

### Высокий приоритет
- **U1. Focus-visible только в app.css последней строкой.** В острове и select фокус клавиатурой не виден. Для приложения с горячими клавишами (PageUp — голос) это заметная дыра. → вынести `:focus-visible` в tokens.css, добавить для `.tile/.icon/.chip/.seg-btn/.swatch`.
- **U2. Нет :active-состояний у основных кнопок.** Hover есть, «нажатие» не отыгрывается: у «жидкого» бренда про это особенно обидно. → `transform: scale(.96)` + укороченная пружина на `.btn/.seg-btn/.swatch/.chip`.
- **U3. Редактор кастомной темы — JSON-поле.** Мощно для инженера, страшно для остальных. → следующий шаг: цветовые пиppers для 5–6 ключевых vars (surface, fg, accent, ok/warn/err) поверх JSON как «простой режим».

### Средний приоритет
- **U4. Индикатор «ядро не подключено»** — текст в титлбаре, легко пропустить при первом запуске. → добавить красную точку в знак Νοῦς (движок уже умеет error-состояние) — статус без чтения.
- **U5. Чипы hello-экрана не показывают, что это кнопки-подсказки.** → лёгкий hover-подъём + иконка стрелки; сейчас только фон меняется.
- **U6. Свёрнутая навигация (<920px) прячет подписи, остаются иконки** — приемлемо, но `title` есть не у всех пунктов. → пройтись title по всем.

### Низкий приоритет
- U7. Фильтр настроек «Найти настройку…» не подсвечивает найденное внутри боксов — бокс просто показывается. Подсветка совпавшей строки ускорит поиск.
- U8. Тосты снизу-по-центру могут перекрывать композер при коротком окне. → сместить выше композера или вправо.

## 4. Интерактивность и отклик

- **Плюсы:** переключение темы мгновенное и бесшовное (проверено кликом); морфинг знака = непрерывная обратная связь о жизни агента; пружинные переходы карточек острова.
- **Минусы:**
  - **I1.** Острову не хватает idle-«дыхания» в пустоте: в idle режиме часы статичны. Лёгкая пульсация двоеточия (как у часов iOS) дала бы ощущение живого без движения.
  - **I2.** Hover-прогрев сегмента темы меняет только цвет текста — добавить фон `--fill-1`, как у остальных кнопок (сейчас непоследовательно).
  - **I3.** Свотчи акцентов — только цветной круг; выбранное состояние (рамка) едва видно на тёмном. → белый gap-ободок + scale 1.15 у выбранного.

## 5. Понятность и насыщенность деталями

- **Понятность:** навигация самоочевидна (иконка+слово), Greek-eyebrow не требует знания греческого (перевод рядом). First-run: hello-чипы дают сценарии «попробуй меня» — правильно.
- **Крючки, которые уже работают:** пульсирующее ядро знака; eyebrow-точка акцентного цвета; tooltip-мифы (легко сделать вирусной фишкой — «а вы знали, что Ἠχώ — нимфа Эхо»); свечение композера при фокусе.
- **Риски перегруза:** на странице настроек сейчас eyebrow вкладки + Χρώμα в бокс + μ-префиксы боксов — верхняя граница нормы по гайдбуку §11.3. Больше греческого на этом экране добавлять нельзя (соблюдено, но запас нулевой).

## 7. Доступность

- **A1 (High).** Reduced-motion в острове глушит все анимации, включая смысловой индикатор знака. Движок Νοῦς умеет статичные состояния — нужно подключить: `prefers-reduced-motion` → морфинг сохраняется, декоративные циклы (blob-остатки, лирика) гасятся. Сейчас остров частично откатывается к «ничего не происходит».
- **A2.** Контраст `--mut` в light (6b6b75 на fbfbfd ≈ 5.9:1) — проходит; но `.act`-чипы 11px в сценариях всё ещё мельче минимума 12px по гайдбуку.
- **A3.** Иконки title имеют почти все; добавить к свотчам акцентов aria-label с именем (`Νύξ · фиолет`).
