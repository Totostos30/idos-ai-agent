## 0. Границы редизайна (Step 1 по методике)

**Должно быть сохранено (идентичность продукта):**
- «Жидкая капсула» в духе Dynamic Island: чёрный остров сверху экрана, пружинные анимации, «капание» карточек.
- Фирменный 4-цветный градиент бренда: `#7c8cff → #b46cff → #4fd1ff → #e07cff` (логотип, орб, кольцо распознавания).
- Анимации по громкости (gwaves, eq, edge-glow) — это signature-деталь продукта.
- Структура трёх окон (остров / главное окно / выделение области) и вся функциональность.

**Может быть переструктурировано:** токены, палитры тем, иконки, шкалы типографики/отступов/радиусов, компонентные стили, копирайт приветствия.

**Главный источник «средности»:** отсутствие единой токен-системы (десятки захардкоженных цветов при объявленных переменных) + эмодзи/разнородные юникод-глифы вместо иконок. Это же блокирует любую темизацию.

**Режим:** `Refinement` с системной переработкой токенов и иконок. Не Full Redesign — структура и бренд-язык остаются.

## 0.1 Направление (Step 2 по методике)

> **Дизайним это как** десктопного голосового агента для Windows-пользователя, **используя** «жидкую капсулу» Dynamic Island с фирменным 4-цветным свечением **вокруг прорыва**: φ — интерфейс говорит на языке своего имени: каждая поверхность несёт греческое слово-отсылку (Μνήμη, Ἠχώ, Ὕπνος…), а знак Νοῦς проживает состояния агента как живой двигатель.

Слой Γλῶτта — не украшение, а **система имён**: каждое греческое слово является настоящим термином для своей функции (Мнемозина — память, Эхо — звук, Гипнос — страж сна) и стоит в строго отведённом слоте (eyebrow над заголовком). Правила размещения, словарь и анти-slop-ограничители — GUIDEBOOK §11. Питомцы исключены из направления.

## J. Порядок исправлений (проходы unslop)

1. **Spacing** — сетка 4px, шкала отступов (D1-D3)
2. **Color** — токен-слой, темы (A1-A8, E1-E5) → см. THEMES.md
3. **Icons** — SVG-набор, удалить эмодзи (B1-B4)
4. **Copy + Γλῶτта** — приветствие и чипы (F2), греческий слой по GUIDEBOOK §11: eyebrows вкладок/разделов, словарь как источник истины
5. **Type** — шкала, tabular-nums (C1-C4)
6. **Layout** — радиусы-шкала, box-in-box (D1, F3)
7. **Details** — focus-visible, скроллбары, reduced-motion (H1-H4)
8. **Motion** — единые токены пружин/длительностей; интеграция морфинг-движка Νοῦς вместо `.orb.s-*` классов (см. GUIDEBOOK §13)
9. **Naming** — финальная выверка Γλῶτты: каждое греческое слово в словаре, ни одного вне слота

Каждый проход — отдельный коммит с проверкой в обоих окнах и обеих темах. Питомцы не входят ни в один проход (решение отклонено).
