# Участие в разработке IDOS

Спасибо за интерес к проекту. Перед изменениями прочитайте [README](README.md), [архитектуру](ARCHITECTURE.md), [установку](INSTALL.md) и [безопасность](SECURITY.md).

Проект распространяется по [лицензии MIT](LICENSE). Отправляя вклад, убедитесь, что имеете право предоставить его на совместимых условиях и что он не содержит материалов с несовместимыми лицензиями.

## Настройка окружения

Подготовьте Windows 10/11, Python 3.11, Node.js 20+, Rust stable/MSVC и зависимости через `scripts\Setup.ps1`. Не добавляйте локальные настройки, ключи, модели, базы данных или содержимое пользовательского профиля в коммиты.

## Перед отправкой изменений

```powershell
.venv\Scripts\python -m unittest discover -s tests
npm run build
cd src-tauri
cargo check --locked
cd ..
```

Для сборки релиза используйте `scripts\Build-Release.ps1`; не добавляйте результаты из `release/`, `dist/` и `src-tauri/target/`.

## Правила изменений

- Сохраняйте совместимость версий: версия задаётся в `core/config.py`, а тест `tests/test_version.py` сверяет связанные манифесты и документацию.
- Добавляйте/обновляйте тесты при изменении поведения. Тесты должны работать без пользовательских ключей и не выполнять реальные внешние действия.
- Не записывайте ключи, пароли, токены, содержимое личных файлов или реальные данные пользователя в исходники, тесты, фикстуры и логи. Не добавляйте временные материалы из `.work/` и `.manus/`.
- Для рискованных действий инструментов явно указывайте категорию действия и проверяйте поведение в каждом режиме `agent.autonomy`.
- Изменения Windows-интеграций проверяйте на Windows; учитывайте недоступность этих функций в демо-режиме и на других ОС.
- Перед публикацией просмотрите весь diff и Git-историю на секреты. `.gitignore` не удаляет то, что уже отслеживается.

## GitHub и публикация

Никогда не отправляйте личные данные в публичный репозиторий. Для исправления уязвимостей или случайно опубликованных секретов используйте приватный канал; отозванный ключ всё равно нужно заменить у провайдера.
